# Writing resources

The templates and manuscript builder were consolidated from Qiushi Engine /
Origo's `extensions/aros_extensions/bundled/skills/research-writing` resources.
SeedEnv maintains this shared source for independent agent hosts and product
integration. Identical layouts share a source file; generated bibliography
intermediates and rendered reference PDFs are not shipped as template inputs.

`standard`, `compact` and `submission` are layout descriptions. The compact
family originated in `nature_final`; the submission family in `submission_style`.
These names do not assert compliance with a journal's current submission rules.

The bundled `sn-nature.bst` retains its LaTeX Project Public License notice.
Upstream TeX packages retain their licenses. SeedEnv's MIT license applies to
SeedEnv code and the project's own writing resources, not that bibliography style.
