% Research Book Template
% Compile with LuaLaTeX.
% Keep figure files under figures/.
% Use refs.bib with \cite{...} when references are used.
% LaTeX supplies section numbers; section titles contain title text only.
% Chapters can be written directly after \mainmatter or included from separate files.

\providecommand{\BookTemplateVersion}{2026.04.30}

% Do not add many packages unless the book truly needs them. This template is
% intentionally conservative so autonomous agents can compile it reliably.
