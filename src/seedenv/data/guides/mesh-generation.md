# Mesh generation · 网格生成

Generate meshes from explicit geometric regions.

Name physical volumes and boundary groups before meshing. Export dimensionality and element order appropriate to the solver, retaining tags needed for material and boundary assignments.

根据几何区域生成计算网格。

划分网格前命名物理体与边界组。按求解器需要输出维数和单元阶数，保留材料及边界赋值所需标记。

Software / 软件：Gmsh Python (`environment-gmsh`).

Use `seedenv context mesh-generation` for software entries and setup on this host.

- https://gmsh.info/doc/texinfo/
