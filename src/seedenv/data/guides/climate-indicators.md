# Climate indicators · 气候指标

Calculate climate indicators from labeled time series.

Keep calendars, units, missing intervals and reference periods explicit. Bias adjustment and indicator calculation are separate operations; aggregate only after deciding how incomplete periods are treated.

从带坐标时间序列计算气候指标。

明确日历、单位、缺失区间与参考期。偏差订正和指标计算分开，聚合前决定不完整时段的处理方式。

Software / 软件：xclim (`python-xclim`).

Use `seedenv context climate-indicators` for software entries and setup on this host.

- https://xclim.readthedocs.io/en/stable/installation.html
