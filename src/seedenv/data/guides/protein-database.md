# Protein structure access · 蛋白质结构数据库连接

Retrieve selected macromolecular structures.

Choose asymmetric unit or biological assembly deliberately. Preserve chain identifiers, missing residues, alternate conformations and experimental metadata when preparing structures.

获取选定的大分子结构。

明确使用不对称单元还是生物组装体。结构准备保留链标识、缺失残基、替代构象和实验元数据。

Software / 软件：RCSB PDB (`connector-pdb`).

Use `seedenv context protein-database` for software entries and setup on this host.

- https://data.rcsb.org/
