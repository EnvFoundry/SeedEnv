# PCB project tools · PCB 工程工具

Read and export schematic and board projects.

Resolve symbol/footprint libraries and net names in the project. Keep electrical connectivity, board geometry and manufacturing layers distinguishable when producing outputs.

处理和导出原理图与电路板工程。

解析项目符号、封装库和网络名称。输出时区分电气连接、板几何与制造图层。

Software / 软件：KiCad (`tool-kicad`).

Use `seedenv context pcb-design` for software entries and setup on this host.

- https://docs.kicad.org/
