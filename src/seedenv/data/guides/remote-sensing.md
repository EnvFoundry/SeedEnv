# Raster remote sensing · 栅格遥感处理

Process georeferenced raster arrays.

Preserve CRS, affine transform, nodata and radiometric units. Choose resampling for the data type and process in windows/chunks when images exceed memory.

处理带地理参考的栅格数组。

保留坐标参考、仿射变换、缺失值和辐射单位。按数据类型选重采样方法，大影像采用窗口或分块处理。

Software / 软件：rioxarray (`python-rioxarray`).

Use `seedenv context remote-sensing` for software entries and setup on this host.

- https://corteva.github.io/rioxarray/stable/getting_started/getting_started.html
