# Molecular dynamics · 分子动力学

Run molecular dynamics with explicit forces and integrators.

Match topology, coordinates, force-field parameters and solvent model. Choose the OpenMM device explicitly; keep minimization, equilibration and production sampling distinguishable.

具有明确力场和积分器的分子动力学。

匹配拓扑、坐标、力场参数和溶剂模型。显式选择 OpenMM 计算设备，区分最小化、平衡与正式采样阶段。

Software / 软件：OpenMM (`python-openmm`).

Use `seedenv context molecular-dynamics` for software entries and setup on this host.

- https://docs.openmm.org/latest/userguide/application/01_getting_started.html

Editable starting program / 可编辑起点：`seedenv example molecular-dynamics --output research.py`.
