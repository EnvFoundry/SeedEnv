# Plasma models · 等离子体计算

Calculate plasma parameters and formulate plasma models.

Carry physical units, particle species and charge state into each calculation. Match collisional, fluid or kinetic assumptions to the regime; parameter formulas alone are not a complete plasma simulation.

等离子体参数与模型计算。

计算中明确物理单位、粒子种类和电荷态。碰撞、流体或动理学假设应符合研究区间；参数公式本身不构成完整仿真。

Software / 软件：PlasmaPy (`python-plasmapy`).

Use `seedenv context plasma-models` for software entries and setup on this host.

- https://docs.plasmapy.org/en/stable/install.html
