# Spatial omics · 空间组学

Relate molecular observations to spatial neighborhoods.

Align spot/cell coordinates, image scale and sample identifiers before building spatial graphs. Keep tissue boundaries and replicate structure in spatial comparisons.

分析分子观测与空间邻域的关系。

建立空间图前对齐点位或细胞坐标、图像尺度和样本标识。空间比较保留组织边界和重复样本结构。

Software / 软件：Squidpy (`python-squidpy`).

Use `seedenv context spatial-omics` for software entries and setup on this host.

- https://squidpy.readthedocs.io/en/stable/installation.html
