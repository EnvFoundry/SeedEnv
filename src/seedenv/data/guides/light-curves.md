# Light curves · 天文光变曲线

Analyze selected photometric time series.

Preserve time reference, cadence and quality flags. Detrending can remove the signal of interest; compare the target timescale with the chosen trend model before searching for events or periodicities.

分析选定的测光时间序列。

保留时间参考、采样节奏和质量标记。去趋势可能削弱目标信号，搜索事件或周期前比较目标时间尺度与趋势模型。

Software / 软件：Lightkurve (`python-lightkurve`).

Use `seedenv context light-curves` for software entries and setup on this host.

- https://lightkurve.github.io/lightkurve/
