# OPC UA connections · OPC UA 连接

Browse and read industrial process data.

Resolve server endpoint, namespace and node identifiers with the host connection. Preserve timestamps, status and units; subscriptions and write operations should use the selected server capabilities explicitly.

浏览和读取工业过程数据。

通过宿主连接明确端点、命名空间与节点。保留时间戳、状态和单位；订阅与写入明确使用选定服务器的能力。

Software / 软件：asyncua (`python-opcua`).

Use `seedenv context opc-ua` for software entries and setup on this host.
