# Atomistic dynamics · 原子尺度动力学

Run atomistic and coarse-grained simulations.

Select units and potential styles before building the input. Match potential files to element ordering and boundary conditions; report the sampling ensemble and thermostat/barostat settings with results.

运行原子与粗粒化动力学计算。

构造输入前选择单位和势函数类型，匹配势文件、元素顺序与边界。结果同时说明采样系综及控温、控压设置。

Software / 软件：LAMMPS (`tool-lammps`).

Use `seedenv context atomistic-dynamics` for software entries and setup on this host.

- https://docs.lammps.org/Manual.html
