# Reaction kinetics · 反应动力学

Simulate reacting mixtures, reactors and flames.

Select a chemical mechanism and its valid temperature/pressure range. State reactor constraints and inlet composition; preserve species ordering and units when passing results to another solver.

反应混合物、反应器与火焰模型。

选择反应机理及其温压适用范围。明确反应器约束与入口组分，向其他求解器传递结果时保留物种顺序和单位。

Software / 软件：Cantera (`python-cantera`).

Use `seedenv context reaction-kinetics` for software entries and setup on this host.

- https://cantera.org/stable/install/index.html

Editable starting program / 可编辑起点：`seedenv example reaction-kinetics --output research.py`.
