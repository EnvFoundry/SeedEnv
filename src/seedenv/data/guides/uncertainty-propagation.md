# Uncertainty propagation · 不确定度传播

Propagate correlated measurement uncertainties.

Construct correlated inputs when calibration terms are shared. First-order propagation is local; use explicit Monte Carlo propagation when curvature or non-Gaussian uncertainty matters.

传播测量不确定度与相关性。

共享标定项应建立相关输入。一阶传播是局部近似；曲率或非高斯不确定度重要时改用显式蒙特卡洛传播。

Software / 软件：uncertainties (`python-uncertainties`).

Use `seedenv context uncertainty-propagation` for software entries and setup on this host.
