# Spectral fitting · 光谱与峰形拟合

Fit spectral models and constrained peak families.

Specify the baseline, instrumental broadening and peak model. Fit on the measured coordinate scale with appropriate weights; overlapping peaks can make parameter combinations identifiable while individual peaks are not.

光谱模型与受约束峰族拟合。

明确基线、仪器展宽和峰形模型，在实测坐标尺度上加权拟合。重叠峰可能只允许识别参数组合，不能可靠分离每个峰。

Software / 软件：lmfit (`python-lmfit`).

Use `seedenv context molecular-spectra` for software entries and setup on this host.

- https://lmfit.github.io/lmfit-py/installation.html
