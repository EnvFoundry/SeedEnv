# Vector search · 向量近邻检索

Build exact and approximate vector indexes.

Keep embedding dimensions, normalization and distance metric consistent. Store the vector-to-record mapping separately and compare an approximate index against exact search on representative queries.

构建精确或近似向量索引。

保持向量维数、归一化与距离度量一致。单独保存向量与原记录的映射，并用代表性查询比较近似索引与精确检索。

Software / 软件：Faiss CPU (`environment-faiss`).

Use `seedenv context vector-search` for software entries and setup on this host.
