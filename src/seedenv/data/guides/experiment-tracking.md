# Experiment tracking · 实验记录服务连接

Connect to a selected experiment tracking service.

Use the existing project and artifact location. Log parameters, measurements and selected artifacts through the service API; credentials and service lifecycle stay with the host.

连接选定的实验记录服务。

使用已有项目与产物位置，通过服务接口记录参数、观测和选定产物；凭证与服务启停由宿主管理。

Software / 软件：MLflow tracking (`connector-mlflow`).

Use `seedenv context experiment-tracking` for software entries and setup on this host.

- https://mlflow.org/docs/latest/
