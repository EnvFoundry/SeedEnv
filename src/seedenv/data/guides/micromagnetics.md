# Micromagnetics · 微磁学

Solve micromagnetic dynamics on a GPU host.

Set exchange, anisotropy, saturation magnetization, geometry and boundary conditions in consistent units. Resolve the magnetic length scales in the mesh; save magnetization fields as well as integrated observables.

在 GPU 主机上求解微磁动力学。

使用一致单位指定交换、各向异性、饱和磁化强度、几何和边界。网格需分辨磁性长度尺度，同时保存磁化场与积分观测量。

Software / 软件：MuMax3 (`tool-mumax`).

Use `seedenv context micromagnetics` for software entries and setup on this host.

- https://mumax.github.io/
