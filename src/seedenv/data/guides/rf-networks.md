# RF networks · 射频网络分析

Analyze measured and simulated scattering networks.

State reference impedance, frequency units and port order. Calibration, de-embedding and renormalization act on different assumptions; retain the measurement reference planes with the network data.

分析实测与仿真的散射网络。

明确参考阻抗、频率单位与端口顺序。校准、去嵌和重归一化的假设不同，数据需保留测量参考面。

Software / 软件：scikit-rf (`python-skrf`).

Use `seedenv context rf-networks` for software entries and setup on this host.

- https://scikit-rf.readthedocs.io/en/latest/tutorials/Installation.html
