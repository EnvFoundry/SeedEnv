# Volatility models · 波动率建模

Fit conditional volatility and related time-series models.

Define returns, scaling and the observation calendar. Separate estimation windows from forecast horizons; retain distributional assumptions and compare forecasts using only information available at each time.

拟合条件波动率及相关时序模型。

明确收益定义、缩放与观测日历。区分估计窗口与预测跨度，保留分布假设，预测仅使用当时可获得的信息。

Software / 软件：ARCH (`python-arch`).

Use `seedenv context volatility-models` for software entries and setup on this host.
