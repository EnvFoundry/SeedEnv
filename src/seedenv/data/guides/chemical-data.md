# Chemical database access · 化学数据库连接

Retrieve selected compound structures and properties.

Resolve identifiers before combining tables. Keep experimental measurements distinct from computed properties and preserve units, conditions and source records in the project.

读取选定化合物结构与性质。

合并表格前明确标识符对应关系。区分实测性质与计算性质，保留单位、条件和来源记录。

Software / 软件：PubChem PUG REST (`connector-pubchem`).

Use `seedenv context chemical-data` for software entries and setup on this host.

- https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest
