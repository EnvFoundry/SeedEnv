# Ephemerides and observers · 星历与观测位置

Calculate celestial positions for specified observers and times.

Choose a particular ephemeris and time scale, and preserve observer coordinates. Download the required ephemeris deliberately; distinguish geometric positions from apparent observing coordinates.

计算指定观测位置与时刻的天体位置。

明确星历、时间尺度和观测坐标，按需下载对应星历。区分几何位置与表观观测坐标。

Software / 软件：Skyfield (`python-skyfield`).

Use `seedenv context orbit-ephemerides` for software entries and setup on this host.
