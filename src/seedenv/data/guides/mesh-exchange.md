# Mesh exchange · 网格与场数据互转

Convert meshes and associated fields between formats.

Keep point/cell data distinct and inspect how each target format represents mixed element types and physical tags. Format conversion does not improve mesh quality or change the underlying model.

转换网格及其关联场数据格式。

区分点数据和单元数据，明确目标格式对混合单元和物理标记的表达。格式转换本身不会改善网格质量或改变模型。

Software / 软件：meshio (`python-meshio`).

Use `seedenv context mesh-exchange` for software entries and setup on this host.

- https://github.com/nschloe/meshio
