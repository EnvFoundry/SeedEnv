# Economic series access · 经济时间序列连接

Retrieve economic series and historical vintages.

Choose units, seasonal adjustment and release vintage. Use values known at the research decision date when modeling historical decisions; revised series answer a different question.

读取经济序列及其历史发布值。

明确单位、季节调整和发布批次。模拟历史决策时使用当时已发布的值，修订后的序列回答的是不同问题。

Software / 软件：FRED / ALFRED (`connector-fred`).

Use `seedenv context economic-data` for software entries and setup on this host.

- https://fred.stlouisfed.org/docs/api/fred/
