# Model datasets · 模型数据集处理

Load, transform and stream selected training datasets.

Choose the dataset configuration and split before loading. Stream when full download is unnecessary, preserve source columns during transformations, and keep large caches at the user-selected data location.

读取、变换与流式处理选定的数据集。

读取前明确数据配置与划分。不需要全量下载时使用流式读取；变换时保留来源列，较大缓存放到用户选定的数据位置。

Software / 软件：Hugging Face Datasets (`python-datasets`).

Use `seedenv context model-datasets` for software entries and setup on this host.

- https://huggingface.co/docs/datasets/installation
