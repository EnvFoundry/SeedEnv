# Assay curve models · 实验响应曲线建模

Fit concentration-response and binding models.

State concentration units, controls and the mechanistic meaning of the curve. Use replicate measurements and an appropriate noise model; an empirical midpoint is not automatically a mechanistic binding constant.

拟合浓度响应与结合模型。

明确浓度单位、对照和曲线机理含义。使用重复观测与合适噪声模型；经验曲线中点不自动等同于机理结合常数。

Software / 软件：lmfit (`python-lmfit`).

Use `seedenv context binding-assays` for software entries and setup on this host.

- https://lmfit.github.io/lmfit-py/installation.html
