# Materials features · 材料特征与数据建模

Construct composition and structure descriptors.

Select descriptors from the physical question and the available structures. Keep target-derived information out of inputs and split by material family or composition when studying transfer to new systems.

构建成分与结构描述符。

根据物理问题和结构可得性选择描述符，避免将目标派生信息放入输入；研究新体系迁移时按材料族或成分划分数据。

Software / 软件：matminer (`python-matminer`).

Use `seedenv context materials-features` for software entries and setup on this host.

- https://hackingmaterials.lbl.gov/matminer/installation.html
