# Aqueous geochemistry · 水溶液地球化学

Model aqueous speciation and geochemical reactions.

Choose the thermodynamic database and activity model with the ionic strength regime. State solution units, phases and charge-balance choices; database changes alter the physical model.

水溶液物种分布与地球化学反应模型。

按离子强度区间选择热力学数据库与活度模型，明确溶液单位、相与电荷平衡处理。数据库变化会改变物理模型。

Software / 软件：PHREEQC (`tool-phreeqc`).

Use `seedenv context aqueous-geochemistry` for software entries and setup on this host.
