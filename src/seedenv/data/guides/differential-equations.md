# Differential equations · 常微分与边值问题

Integrate ODEs and solve boundary-value problems.

Specify the state, units, initial/boundary conditions and events. Use solve_ivp or solve_bvp; choose a stiff method when timescales separate and compare trajectories at tighter tolerances.

求解常微分方程与边值问题。

明确状态、单位、初始或边界条件及事件；使用 solve_ivp 或 solve_bvp。时间尺度分离时选择刚性算法，并比较收紧误差后的轨迹。

Software / 软件：NumPy / SciPy (`python-numerics`).

Use `seedenv context differential-equations` for software entries and setup on this host.
