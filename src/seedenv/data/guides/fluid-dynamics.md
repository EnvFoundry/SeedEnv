# Computational fluid dynamics · 计算流体动力学

Run case-based finite-volume fluid simulations.

Specify dimensions, flow regime, boundary conditions and transport properties before selecting a solver. Keep mesh generation separate from time stepping and examine flux balance and relevant field outputs.

运行基于算例目录的有限体积流体仿真。

选择求解器前明确量纲、流动区间、边界和输运参数。区分网格生成与时间推进，观察通量平衡及目标场量。

Software / 软件：OpenFOAM (`tool-openfoam`).

Use `seedenv context fluid-dynamics` for software entries and setup on this host.
