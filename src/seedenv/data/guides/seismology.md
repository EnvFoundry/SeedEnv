# Seismology · 地震学信号分析

Process seismic waveforms and station metadata.

Preserve absolute timing, station/channel identity and instrument response. Remove response within its supported frequency range before comparing physical amplitudes between stations.

处理地震波形与台站元数据。

保留绝对时间、台站通道标识与仪器响应。比较不同台站的物理振幅前，在适用频率范围内去除仪器响应。

Software / 软件：ObsPy (`python-obspy`).

Use `seedenv context seismology` for software entries and setup on this host.

- https://docs.obspy.org/
