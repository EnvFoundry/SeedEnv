# Panel econometrics · 面板计量

Fit panel and instrumental-variable models.

Define entity/time indexes and fixed effects before estimation. Match covariance treatment to the sampling structure, and state the identifying assumptions for instrumental variables.

面板与工具变量模型拟合。

估计前定义个体、时间索引与固定效应。协方差处理应符合抽样结构，工具变量模型需明确识别假设。

Software / 软件：linearmodels (`python-linearmodels`).
