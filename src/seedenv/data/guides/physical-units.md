# Physical units · 物理单位计算

Calculate with explicit units and dimensional conversions.

Declare unit conventions at file and API boundaries. Distinguish offset units from multiplicative units and attach dimensions before combining data from different instruments.

带显式单位的计算与量纲转换。

在文件和接口交界处定义单位约定，区分偏移单位与比例单位。合并不同仪器数据前先补全量纲。

Software / 软件：Pint (`python-pint`).

Use `seedenv context physical-units` for software entries and setup on this host.
