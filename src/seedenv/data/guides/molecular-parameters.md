# Molecular force-field parameters · 分子力场参数化

Assign molecular parameters with explicit chemistry and force fields.

Preserve stereochemistry, bond orders and charge state. Choose force-field and charge methods together, then export a system compatible with the intended simulation engine.

基于明确化学结构与力场分配分子参数。

保留立体化学、键级和电荷态。共同选择力场与电荷方法，再输出与目标模拟引擎兼容的体系。

Software / 软件：OpenFF Toolkit (`environment-openff`).

Use `seedenv context molecular-parameters` for software entries and setup on this host.

- https://docs.openforcefield.org/projects/toolkit/en/stable/installation.html
