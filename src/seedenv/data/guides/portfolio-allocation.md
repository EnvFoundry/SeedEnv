# Portfolio allocation · 投资组合配置研究

Study portfolio objectives and allocation constraints.

Define return horizon, covariance estimate, bounds and transaction-cost assumptions. Align assets and timestamps, and evaluate chosen allocations on later observations rather than the fitting window.

研究组合目标与配置约束。

明确收益周期、协方差估计、边界和交易成本假设。对齐资产与时间戳，用后续观测研究配置表现。

Software / 软件：PyPortfolioOpt (`python-portfolio`).

Use `seedenv context portfolio-allocation` for software entries and setup on this host.
