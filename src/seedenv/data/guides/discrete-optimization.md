# Discrete optimization · 离散优化与调度

Model integer constraints, routing and schedules.

For CP-SAT, convert quantities to consistent integer units and state capacity/time constraints. Distinguish a feasible solution from a proven optimum using the solver status and bound.

整数约束、路径规划与调度模型。

CP-SAT 输入采用一致的整数单位，明确容量和时间约束；通过求解状态与界区分可行解和最优解。

Software / 软件：OR-Tools (`python-ortools`).

Use `seedenv context discrete-optimization` for software entries and setup on this host.

- https://developers.google.com/optimization/install/python

Editable starting program / 可编辑起点：`seedenv example discrete-optimization --output research.py`.
