# Bayesian models · 贝叶斯建模

Build probabilistic models and inspect posterior predictions.

Express the likelihood and priors in data units. Compare prior and posterior predictive behavior, preserve chain coordinates, and examine parameter dependence before interpreting individual posterior means.

概率模型、后验推断与预测。

按数据单位定义似然和先验，比较先验与后验预测行为，保留链的坐标。解释单个参数均值前先观察参数相关性。

Software / 软件：PyMC / ArviZ (`python-pymc`).

Use `seedenv context bayesian-models` for software entries and setup on this host.
