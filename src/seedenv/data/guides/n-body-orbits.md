# N-body orbits · 引力多体轨道

Integrate gravitational many-body systems.

Specify masses, units and the coordinate convention for orbital elements. Choose integrator and timestep for encounters and timescales; retain energy/angular-momentum histories alongside orbital outputs.

积分引力多体系统。

明确质量、单位和轨道要素坐标约定。按近遇与时间尺度选择积分器和步长，同时保存能量、角动量及轨道历史。

Software / 软件：REBOUND (`python-rebound`).

Use `seedenv context n-body-orbits` for software entries and setup on this host.

- https://rebound.readthedocs.io/en/latest/quickstart_installation/
