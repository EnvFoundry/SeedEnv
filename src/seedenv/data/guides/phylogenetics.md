# Phylogenetic structures · 系统发育结构

Manipulate trees, taxa and evolutionary character data.

Use one taxon namespace when comparing trees and state rooting and branch-length meaning. Tree distances depend on shared taxa and whether branch lengths are included.

操作系统发育树、分类单元与性状数据。

比较树时使用一致分类单元集合，说明根与枝长含义。树距离取决于共享分类单元以及是否考虑枝长。

Software / 软件：DendroPy (`python-dendropy`).

Use `seedenv context phylogenetics` for software entries and setup on this host.

- https://jeetsukumaran.github.io/DendroPy/
