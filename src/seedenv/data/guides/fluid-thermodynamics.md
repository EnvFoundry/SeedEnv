# Fluid thermodynamics · 流体热力学

Calculate mixture properties and phase equilibria.

Specify composition basis, temperature, pressure and property model. Track phase identity and mixing rules; extrapolating a correlation beyond its fitted range is a separate modeling assumption.

混合物性质与相平衡计算。

明确组成基准、温度、压力和物性模型。保留相态与混合规则，超出拟合区间外推需单独说明模型假设。
