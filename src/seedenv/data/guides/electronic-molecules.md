# Molecular electronic structure · 分子电子结构

Compute molecular electronic states and energies.

Specify geometry units, charge, spin, basis and electronic method. Compare basis and method dependence for the target observable; a converged SCF solution can still represent a different electronic state.

计算分子电子态与能量。

明确几何单位、电荷、自旋、基组与电子结构方法。考察目标量对基组和方法的依赖；SCF 收敛的解仍可能对应不同电子态。

Software / 软件：PySCF (`python-pyscf`).

Use `seedenv context electronic-molecules` for software entries and setup on this host.

- https://pyscf.org/user/install.html

Editable starting program / 可编辑起点：`seedenv example electronic-molecules --output research.py`.
