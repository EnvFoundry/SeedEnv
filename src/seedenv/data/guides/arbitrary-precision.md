# Arbitrary precision · 任意精度计算

Evaluate special functions, quadratures and roots at chosen precision.

Set working precision before constructing decimal inputs. Increase precision to study cancellation; additional digits do not repair an ill-posed model or guarantee the correct root.

指定精度的特殊函数、积分与求根。

在构造十进制输入前设置精度。提高精度观察抵消误差；额外位数不能修复病态模型，也不保证找到目标根。

Software / 软件：mpmath (`python-mpmath`).

Use `seedenv context arbitrary-precision` for software entries and setup on this host.

- https://mpmath.org/doc/current/
