# Trajectory analysis · 分子轨迹分析

Analyze molecular trajectories and time-dependent structures.

Load matching topology and trajectory files. Handle periodic boundaries before distances or alignment, define atom selections explicitly, and account for autocorrelation when averaging observables.

分析分子轨迹与结构随时间的变化。

加载配套拓扑与轨迹。计算距离或对齐前处理周期边界，明确原子选择，平均观测量时考虑自相关。

Software / 软件：MDAnalysis (`python-mdanalysis`).

Use `seedenv context trajectory-analysis` for software entries and setup on this host.

- https://userguide.mdanalysis.org/stable/installation.html
