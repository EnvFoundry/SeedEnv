# Sequence read mapping · 测序读段映射

Map reads and assemblies to a chosen reference.

Choose a preset matching read technology and divergence. Keep the reference assembly and contig names with the alignment; mapping quality is not interchangeable with base quality.

将读段或组装序列映射到选定参考。

选择适合测序技术与差异程度的预设，保留参考组装与序列名称。映射质量与碱基质量的含义不同。

Software / 软件：minimap2 (`tool-minimap2`).

Use `seedenv context read-mapping` for software entries and setup on this host.

- https://github.com/lh3/minimap2
