# Plane-wave electronic structure · 平面波电子结构

Compute periodic electronic structures with plane-wave DFT.

Choose pseudopotentials, exchange-correlation functional, cutoffs and k-point sampling consistently. Keep charge density and wavefunction outputs only as needed for the intended follow-up calculation.

周期结构的平面波密度泛函计算。

一致地选择赝势、交换关联泛函、截断和 k 点采样。根据后续计算的需要保存电荷密度与波函数。

Software / 软件：Quantum ESPRESSO (`tool-qe`).

Use `seedenv context plane-wave-dft` for software entries and setup on this host.

- https://www.quantum-espresso.org/Doc/user_guide/
