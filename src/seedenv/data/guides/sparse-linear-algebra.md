# Sparse linear algebra · 稀疏线性代数

Solve sparse systems and partial eigenspectra.

Build sparse operators without densifying them. Choose a solver for symmetry and definiteness; report residuals in the original equation and preserve index ordering when exchanging matrices.

稀疏方程组、部分特征谱与迭代求解。

保持矩阵稀疏，根据对称性和正定性选择求解器。返回原方程残差；交换矩阵时保留行列索引的含义。

Software / 软件：NumPy / SciPy (`python-numerics`).
