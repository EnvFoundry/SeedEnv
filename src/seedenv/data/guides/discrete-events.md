# Discrete-event simulation · 离散事件仿真

Simulate resource queues and event-driven processes.

Define processes, resource capacity and event-time distributions. Separate warm-up from steady-state summaries and retain variability across repeated simulated histories.

资源队列与事件驱动过程仿真。

定义过程、资源容量和事件时间分布。区分预热与稳态统计，保留重复仿真之间的变化。

Software / 软件：SimPy (`python-simpy`).

Use `seedenv context discrete-events` for software entries and setup on this host.

- https://simpy.readthedocs.io/en/latest/
