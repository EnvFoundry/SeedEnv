# Control systems · 控制系统分析

Analyze and design dynamic feedback systems.

Choose continuous or discrete time and define inputs, states and outputs. Distinguish open-loop and closed-loop models; inspect stability and bandwidth under the physical actuator and sensor assumptions.

动态反馈系统的分析与设计。

选择连续或离散时间，定义输入、状态与输出。区分开环与闭环，在执行器和传感器假设下观察稳定性与带宽。

Software / 软件：python-control (`python-control`).

Use `seedenv context control-systems` for software entries and setup on this host.

- https://python-control.readthedocs.io/en/latest/

Editable starting program / 可编辑起点：`seedenv example control-systems --output research.py`.
