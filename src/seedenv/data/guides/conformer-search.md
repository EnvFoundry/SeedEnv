# Conformer search · 分子构象生成

Generate and compare molecular conformers.

Preserve stereochemistry and protonation while generating 3D conformers. Optimize and cluster with a stated force field and distance convention; conformer scores are not binding free energies.

生成与比较分子构象。

生成三维构象时保持立体化学与质子化状态。采用明确力场和距离约定优化、聚类；构象评分不能等同于结合自由能。

Software / 软件：RDKit · 分子数据 (`python-molecules`).

Use `seedenv context conformer-search` for software entries and setup on this host.

- https://rdkit.org/docs/Install.html
