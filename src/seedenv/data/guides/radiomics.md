# Radiomic features · 影像组学特征

Extract defined image and region features.

Record mask labels, resampling, intensity normalization and discretization. Feature definitions depend on these choices; compare acquisition and segmentation effects before combining cohorts.

提取明确的影像与区域特征。

记录掩模标签、重采样、强度归一化和离散化方式。特征取决于这些选择，合并队列前分析采集与分割差异。

Software / 软件：PyRadiomics (`environment-radiomics`).

Use `seedenv context radiomics` for software entries and setup on this host.

- https://pyradiomics.readthedocs.io/en/latest/installation.html
