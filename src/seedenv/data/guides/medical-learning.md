# Medical image learning · 医学影像学习

Build image-learning pipelines with spatial transforms.

Keep images and labels aligned through every transform and split by patient or acquisition source. Choose a task-specific model and weights explicitly; installing the framework does not supply a trained clinical model.

构建含空间变换的影像学习流程。

所有变换保持图像与标签对齐，按患者或采集来源划分数据。明确选择模型与权重；安装框架本身不会提供训练好的临床模型。

Software / 软件：MONAI / PyTorch (`environment-monai`).

Use `seedenv context medical-learning` for software entries and setup on this host.
