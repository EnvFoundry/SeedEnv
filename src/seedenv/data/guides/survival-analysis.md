# Survival analysis · 生存与事件时间分析

Model time-to-event data with censoring.

Define time origin, event coding, censoring and entry time before fitting. Compare proportional-hazard assumptions with alternatives when effects vary over time.

包含删失的事件时间建模。

拟合前定义时间原点、事件编码、删失与进入时间。效应随时间变化时，比较比例风险假设及其他模型。

Software / 软件：lifelines (`python-lifelines`).

Use `seedenv context survival-analysis` for software entries and setup on this host.

- https://lifelines.readthedocs.io/en/latest/

Editable starting program / 可编辑起点：`seedenv example survival-analysis --output research.py`.
