# Robot and sensor frames · 机器人与传感器坐标系

Compose rigid transforms between robot, tool, sample and sensor frames.

State transform direction, length units, rotation convention and time. Name the robot, tool, camera and sample frames explicitly. The example composes supplied rigid transforms; measured hand–eye calibration remains a separate experiment.

明确变换方向、长度单位、旋转约定和时间。以带名称的坐标系保存工具、相机和样品之间的变换；标定结果随装配改变。示例只演示已给定的刚体变换组合，不能代替实际手眼标定。

Software / 软件：pytransform3d (`python-pytransform3d`).
