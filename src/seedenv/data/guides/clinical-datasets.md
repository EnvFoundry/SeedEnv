# Research dataset access · 医学研究数据连接

Connect selected physiology and clinical research datasets.

Select the dataset, cohort and required records before transferring data. Retain sampling frequencies, channel units and event definitions; account access is handled by the host.

连接选定的生理与医学研究数据集。

传输前选择数据集、队列及需要的记录。保留采样率、通道单位和事件定义；账户连接由宿主管理。

Software / 软件：PhysioNet (`connector-physionet`).

Use `seedenv context clinical-datasets` for software entries and setup on this host.

- https://physionet.org/about/database/
