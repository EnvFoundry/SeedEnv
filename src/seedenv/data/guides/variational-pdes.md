# Variational PDEs · 变分形式偏微分方程

Solve weak-form PDEs with finite elements.

Write the weak form, function spaces and boundary conditions before assembling. Preserve mesh markers and MPI partition semantics; compare relevant integrals as the mesh and polynomial order change.
