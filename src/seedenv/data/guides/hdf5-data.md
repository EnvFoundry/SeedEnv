# HDF5 data · HDF5 数据

Read and write hierarchical array datasets.

Choose dataset shape, chunking and compression from the access pattern. Preserve axis meaning and units as metadata; use slicing rather than loading a whole file into memory.

读取与写入分层数组数据集。

按访问方式选择数据形状、分块与压缩，元数据保留坐标轴含义和单位。使用切片，避免全量载入内存。

Software / 软件：h5py (`python-hdf5`).

Use `seedenv context hdf5-data` for software entries and setup on this host.

- https://docs.h5py.org/en/stable/
