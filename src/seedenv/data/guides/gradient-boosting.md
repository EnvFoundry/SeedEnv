# Gradient boosting · 梯度提升与表格学习

Train boosted-tree models on tabular data.

Fit preprocessing only on training data and use group/time splits when observations are related. Save feature order and missing-value conventions with the model; tune depth and regularization against held-out loss.

表格数据的梯度提升树训练。

预处理仅在训练数据上拟合；有关联的样本采用组别或时间划分。模型同时保存特征顺序和缺失值约定。

Software / 软件：XGBoost (`python-xgboost`).

Use `seedenv context gradient-boosting` for software entries and setup on this host.
