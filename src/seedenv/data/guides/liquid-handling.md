# Liquid handling · 液体处理与实验板操作

Compose liquid-handling operations from an explicit deck and resource model.

Choose a backend and define deck, labware, wells, tips and volumes. Install only its required USB/serial extras. Liquid properties, dead volume and carryover need apparatus-specific parameters. Chatterbox previews operations and resource state without measuring real transfer accuracy.

在所选 backend 上定义 deck、实验板、孔位、吸头和体积，按所需接口补充 usb/serial 等依赖。液体性质、液面高度、死体积和残留影响实验结果，需要实际装置参数。Chatterbox 可预演动作及资源状态，不能表明真实移液精度。

Software preparation leaves the laboratory connection with the host. Use the named device selected for this task; keep acquisition data in the project.
软件准备后，由宿主连接本任务选定的设备；采集数据保存在研究项目内。

Software / 软件：PyLabRobot (`python-pylabrobot`).

- [Upstream documentation](https://docs.pylabrobot.org/stable/user_guide/_getting-started/installation.html)
