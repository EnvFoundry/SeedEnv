# Astronomical spectra · 天文光谱分析

Manipulate spectra, continua and spectral lines.

Carry spectral-axis units, uncertainty and masks. State wavelength/frequency and rest/observed-frame conventions; fit continua separately when interpreting integrated line fluxes.

天文光谱、连续谱与谱线处理。

保留谱轴单位、不确定度和掩模。明确波长或频率、静止系或观测系约定；解释谱线积分通量时单独处理连续谱。

Software / 软件：specutils (`python-specutils`).

Use `seedenv context astronomical-spectra` for software entries and setup on this host.

- https://specutils.readthedocs.io/en/stable/
