# Single-cell analysis · 单细胞分析

Analyze expression matrices with cell and gene annotations.

Preserve raw counts and sample identities in AnnData. Explain filtering, normalization and batch treatment; embeddings visualize neighborhoods and do not by themselves establish developmental trajectories.

分析带细胞与基因注释的表达矩阵。

在 AnnData 中保留原始计数和样本标识。明确过滤、归一化与批次处理；嵌入展示邻域，本身不能证明发育轨迹。

Software / 软件：Scanpy (`python-scanpy`).

Use `seedenv context single-cell` for software entries and setup on this host.

- https://scanpy.readthedocs.io/en/stable/installation.html

Editable starting program / 可编辑起点：`seedenv example single-cell --output research.py`.
