# Parameterized notebooks · 参数化笔记本运行

Execute notebook templates with explicit parameters.

Declare the parameters cell and choose an existing kernel. Write each run to a separate output notebook so changing parameters does not overwrite the template or hide failed cells.

使用明确参数执行笔记本模板。

声明参数单元并选择已有内核。每次运行写入独立输出笔记本，避免覆盖模板或隐藏失败单元。

Software / 软件：Papermill (`python-papermill`).

Use `seedenv context parameterized-notebooks` for software entries and setup on this host.

- https://papermill.readthedocs.io/en/latest/installation.html
