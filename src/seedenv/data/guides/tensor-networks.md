# Tensor networks · 张量网络

Construct tensor networks and solve many-body models.

Specify local dimensions, boundary conditions and index conventions. Bond dimension and truncation change the approximation; compare observables as these controls are varied.

张量网络表示与多体模型求解。

明确局部维数、边界条件与指标约定。键维度和截断影响近似，改变这些设置并比较目标可观测量。

Software / 软件：quimb (`python-quimb`).

Use `seedenv context tensor-networks` for software entries and setup on this host.
