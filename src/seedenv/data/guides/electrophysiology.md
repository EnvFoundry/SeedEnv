# Electrophysiology · 电生理信号分析

Analyze EEG, MEG and related event-aligned recordings.

Preserve channel type, units, montage and event timing. Choose referencing and filters before epoching, and fit learned artifact transforms only on the intended training portion.

分析 EEG、MEG 与事件对齐记录。

保留通道类型、单位、空间配置和事件时间。分段前明确参考与滤波，学习型伪迹变换只使用指定训练部分。

Software / 软件：MNE-Python (`python-mne`).

Use `seedenv context electrophysiology` for software entries and setup on this host.
