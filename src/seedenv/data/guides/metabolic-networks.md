# Metabolic networks · 代谢网络

Solve constraint-based metabolic network models.

State reaction bounds, medium and the objective before optimization. Keep mass-balance stoichiometry explicit; an optimal flux distribution may be one of many equivalent solutions.

求解基于约束的代谢网络模型。

优化前明确反应边界、培养基和目标。保留质量守恒化学计量；最优通量分布可能只是多个等价解之一。

Software / 软件：COBRApy (`python-cobra`).

Use `seedenv context metabolic-networks` for software entries and setup on this host.

- https://cobrapy.readthedocs.io/en/latest/
