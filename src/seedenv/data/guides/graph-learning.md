# Graph learning · 图机器学习

Train models on node, edge and graph representations.

Define directedness, edge features and batching semantics. Split at the unit matching deployment, such as unseen graphs or future edges; compute neighborhood features without leaking held-out labels.

节点、边与图表示上的模型训练。

明确有向性、边特征与批处理规则。按实际应用对象划分未见图或未来边；构造邻域特征时避免引入留出标签。

Software / 软件：PyTorch Geometric (`environment-pyg`).

Use `seedenv context graph-learning` for software entries and setup on this host.
