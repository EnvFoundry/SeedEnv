# Agent-based simulation · 经济主体仿真

Simulate interacting agents and institutions.

State agent rules, interaction topology and update order. Compare repeated realizations and aggregate statistics; emergent behavior depends on these modeling choices and the initial population.

模拟相互作用的主体与制度。

明确主体规则、相互作用拓扑和更新顺序。比较重复模拟与整体统计，涌现行为取决于这些选择及初始群体。

Software / 软件：Mesa (`python-mesa`).

Use `seedenv context agent-based-economics` for software entries and setup on this host.

- https://mesa.readthedocs.io/en/stable/
