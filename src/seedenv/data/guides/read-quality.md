# Read preprocessing · 测序读段预处理

Inspect and filter FASTQ reads.

State adapter, quality and length settings and preserve paired-read correspondence. Keep counts before and after filtering; aggressive trimming can change the biological signal downstream.

检查并过滤 FASTQ 读段。

明确接头、质量和长度设置，保持双端对应关系。保留处理前后数量；过强修剪会改变后续生物信号。

Software / 软件：fastp (`tool-fastp`).

Use `seedenv context read-quality` for software entries and setup on this host.

- https://github.com/OpenGene/fastp
