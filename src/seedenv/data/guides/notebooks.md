# Interactive notebooks · 交互式研究笔记本

Run editable notebooks in a selected research kernel.

Choose the kernel interpreter explicitly and keep computation in project files. Connect through the product interface; starting a notebook server should not silently expose it on a public network.

在选定研究内核中运行可编辑笔记本。

显式选择内核解释器，计算文件放在项目中。通过产品接口连接，启动笔记本服务不应自动公开到公网。

Software / 软件：JupyterLab (`python-jupyter`).

Use `seedenv context notebooks` for software entries and setup on this host.

- https://jupyterlab.readthedocs.io/en/stable/getting_started/installation.html
