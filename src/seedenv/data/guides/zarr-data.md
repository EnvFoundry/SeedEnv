# Chunked array storage · Zarr 分块数组

Store and access chunked arrays locally or through connected stores.

Choose chunk shape around expected slicing and parallel writes. Keep array coordinates and attributes with the data; object-store credentials are supplied by the host connection.

在本地或已连接存储中保存与读取分块数组。

根据预期切片与并行写入方式选择块形状，保留坐标和属性；对象存储凭证由宿主连接提供。

Software / 软件：Zarr (`python-zarr`).

Use `seedenv context zarr-data` for software entries and setup on this host.

- https://zarr.readthedocs.io/en/stable/
