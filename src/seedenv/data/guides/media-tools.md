# Research media tools · 研究音视频工具

Convert and inspect experimental audio and video.

Preserve frame timing, pixel format and sampling rate when measurements depend on them. Use lossless or explicitly chosen encoding for analysis inputs; presentation compression is a separate output choice.

转换和查看实验音视频。

测量依赖时间时保留帧时序、像素格式和采样率。分析输入采用无损或明确指定编码，展示压缩另行输出。

Software / 软件：FFmpeg (`tool-ffmpeg`).

Use `seedenv context media-tools` for software entries and setup on this host.

- https://ffmpeg.org/documentation.html
