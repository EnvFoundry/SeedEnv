# Image registration · 影像配准

Estimate and apply image registration transforms.

Specify fixed and moving images and the physical transform direction. Retain the transform chain and interpolation choices; visual overlap alone does not establish anatomical correspondence.

估计并应用影像配准变换。

明确固定图像、移动图像和物理变换方向。保留变换链与插值选择；视觉重叠不等于解剖对应关系成立。

Software / 软件：ANTsPy (`python-ants`).

Use `seedenv context image-registration` for software entries and setup on this host.

- https://antspy.readthedocs.io/en/latest/
