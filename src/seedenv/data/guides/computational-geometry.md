# Computational geometry · 计算几何

Construct spatial queries, triangulations and convex hulls.

Use scipy.spatial for the chosen dimension and distance metric. Separate coordinate transformations from geometry; degenerate or nearly coincident points can change a triangulation.

空间近邻、三角剖分与凸包。

使用 scipy.spatial，并明确维数、距离度量和坐标变换。重合或近退化点会改变剖分，原始坐标与几何结果分开保存。

Software / 软件：NumPy / SciPy (`python-numerics`).

Use `seedenv context computational-geometry` for software entries and setup on this host.
