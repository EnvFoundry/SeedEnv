# Solar data · 太阳物理数据

Read solar observations and their coordinate systems.

Keep observation time, coordinate frame and instrument metadata with maps. Align observations using their physical coordinates; a selected data query should not imply downloading a full archive.

读取太阳观测及其坐标系统。

太阳图像保留观测时刻、坐标系与仪器元数据。使用物理坐标对齐，只下载查询所需数据。

Software / 软件：SunPy (`python-sunpy`).

Use `seedenv context solar-physics` for software entries and setup on this host.

- https://docs.sunpy.org/en/stable/installation.html
