# Transformer models · Transformer 模型使用

Use tokenizers and pretrained model APIs in a chosen runtime.

Choose the task head, tokenizer, context length and compute dtype together. Download only the selected checkpoint; large models and acceleration libraries are not implied by installing the Python API.

在选定运行环境中使用分词器与预训练模型。

同时选择任务头、分词器、上下文长度和计算精度。只下载选定权重；安装 Python 接口并不意味着已经具备大型模型和加速后端。

Software / 软件：Transformers / PyTorch (`environment-transformers`).

Use `seedenv context transformer-models` for software entries and setup on this host.

- https://huggingface.co/docs/transformers/installation
