# Lattice dynamics · 晶格动力学与声子

Construct force constants and phonon spectra.

Generate displacements from a specified structure and supercell, then obtain forces from a compatible calculator. Keep force units and atom ordering consistent; imaginary branches require interpreting the structure and approximation.

构建力常数与声子谱。

根据结构和超胞生成位移，由适配的计算器返回力。保持力的单位与原子顺序一致，并结合结构与近似解释虚频。

Software / 软件：Phonopy (`environment-phonopy`).

Use `seedenv context phonons` for software entries and setup on this host.

- https://phonopy.github.io/phonopy/install.html

Editable starting program / 可编辑起点：`seedenv example phonons --output research.py`.
