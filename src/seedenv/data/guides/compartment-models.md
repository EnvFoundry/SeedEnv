# Compartment dynamics · 房室动力学

Solve mass-balance compartment models for research.

Define compartment volumes, transfer laws and observation equations in consistent units. Treat interventions as explicit inputs and examine which parameter combinations the observations can identify.

求解研究用途的房室质量守恒模型。

以一致单位定义房室体积、转运规律与观测方程。把外部输入明确写入模型，并分析观测可以识别哪些参数组合。

Software / 软件：NumPy / SciPy (`python-numerics`).

Use `seedenv context compartment-models` for software entries and setup on this host.
