# Derivative valuation · 衍生品估值

Build instrument models, curves and valuation calculations.

Set evaluation date, business calendar, day-count convention and cash-flow schedule explicitly. Keep calibration instruments separate from the pricing target and use consistent market quote units.

构造合约模型、曲线与估值计算。

明确估值日、交易日历、计息约定与现金流计划。区分标定合约和估值目标，保持市场报价单位一致。

Software / 软件：QuantLib (`python-quantlib`).

Use `seedenv context derivatives-pricing` for software entries and setup on this host.

- https://www.quantlib.org/install.shtml

Editable starting program / 可编辑起点：`seedenv example derivatives-pricing --output research.py`.
