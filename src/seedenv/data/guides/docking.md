# Molecular docking · 分子对接

Search ligand poses in a specified receptor region.

Prepare receptor and ligand protonation, atom types and search box explicitly. Keep alternate poses and search settings; docking scores rank a model and are not measured binding affinities.

在指定受体区域搜索配体构象。

明确受体和配体质子化、原子类型及搜索框。保留候选姿态与搜索设置；对接评分不是实测结合亲和力。

Software / 软件：AutoDock Vina (`tool-vina`).

Use `seedenv context docking` for software entries and setup on this host.

- https://autodock-vina.readthedocs.io/en/latest/installation.html
