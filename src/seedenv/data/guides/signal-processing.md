# Signal processing · 信号处理

Filter signals and estimate spectra and correlations.

Carry sampling rate and time origin with the signal. Specify windowing, normalization and filter phase behavior; do not interpret aliased frequencies as resolved physical components.

信号滤波、频谱与相关估计。

信号保留采样率和时间原点，明确窗函数、归一化和滤波相位。混叠频率不能解释为已分辨的物理分量。

Software / 软件：NumPy / SciPy (`python-numerics`).

Use `seedenv context signal-processing` for software entries and setup on this host.
