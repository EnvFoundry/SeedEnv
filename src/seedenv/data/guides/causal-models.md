# Causal models · 因果建模

Represent causal assumptions and estimate identified effects.

State treatment, outcome, confounders and the causal graph before choosing an estimator. Identification follows assumptions about the data-generating process; predictive accuracy alone does not identify a causal effect.

表达因果假设并估计可识别的效应。

先明确处理、结果、混杂变量和因果图，再选估计方法。可识别性来自数据生成过程的假设，预测准确率不能替代这一条件。

Software / 软件：DoWhy (`python-dowhy`).
