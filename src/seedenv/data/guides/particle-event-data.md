# Particle event data · 粒子物理事件数据

Read ROOT event trees and fit physics distributions.

Define branches, event weights and selections explicitly. Stream only needed columns, propagate weighted statistical errors, and keep the fitted model range separate from the plotted range.

ROOT 事件树读取与物理分布拟合。

明确分支、事件权重和筛选条件。仅读取需要的列，传播加权统计误差，区分拟合区间与绘图区间。

Software / 软件：ROOT (`environment-root`).

Use `seedenv context particle-event-data` for software entries and setup on this host.

- https://root.cern/install/
